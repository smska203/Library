📋 Техническое задание: Пет-проект «Библиотека» (Console Library)
🎯 Цель проекта
Закрепить на практике темы уроков 1–9: примитивы, ссылочные типы, классы и объекты, конструкторы, перегрузку, this, пакеты, модификаторы доступа, static/final, области видимости переменных.

🧩 Общее описание
Консольное приложение — простая библиотека книг. Пользователь через меню может добавлять книги, искать их, выдавать/возвращать, смотреть статистику. Данные хранятся только в оперативной памяти (без файлов и БД).

📦 Структура проекта (пакеты)
Проект должен быть разбит минимум на 3 пакета:

text
com.library.app        — точка входа (main) и меню
com.library.model      — модели данных (Book, Reader, Library)
com.library.util       — вспомогательные классы (InputHelper, Constants)
Требования по модификаторам доступа:

Поля классов — private (инкапсуляция).

Геттеры/сеттеры — public.

Вспомогательные методы внутри класса — private.

Константы — public static final.

Класс с main — public.

🏗️ Классы и их требования
1. Book (пакет com.library.model)
Поля (все private):

int id — уникальный идентификатор

String title — название

String author — автор

int year — год издания

boolean isAvailable — доступна ли книга (по умолчанию true)

Требования:

Статическое поле-счётчик private static int counter, автоматически присваивающее id при создании объекта.

Два конструктора (перегрузка):

Book(String title, String author) — год по умолчанию (например, 0 или -1)

Book(String title, String author, int year)

Второй конструктор должен вызывать первый через this(...).

Метод printInfo() — выводит информацию о книге в читаемом виде.

Метод changeAvailability() — меняет isAvailable на противоположное (подумай, нужен ли setAvailable).

Геттеры для всех полей. Сеттер только для year (с проверкой, что год > 0).

2. Reader (пакет com.library.model)
Поля (private):

int id (статический счётчик, как у Book)

String name

Book[] borrowedBooks — массив выданных книг (например, до 5 штук)

int borrowedCount — сколько книг сейчас на руках

Требования:

Конструктор Reader(String name).

Метод boolean takeBook(Book book) — если есть место и книга доступна, добавляет её и возвращает true, иначе false.

Метод boolean returnBook(Book book) — ищет книгу среди выданных, «возвращает» её и возвращает true, иначе false.

Метод printBorrowedBooks() — печатает список книг на руках.

Геттеры для id, name, borrowedCount.

3. Library (пакет com.library.model)
Поля (private):

Book[] books — все книги библиотеки (массив фиксированного размера, например 20)

Reader[] readers — все читатели (например, до 10)

int bookCount

int readerCount

Требования:

Метод void addBook(Book book) — добавляет книгу, если есть место.

Метод Reader registerReader(String name) — создаёт и регистрирует читателя.

Метод Book findBookById(int id) — возвращает книгу или null.

Метод Book findBookByTitle(String title) — поиск по названию (без учёта регистра через equalsIgnoreCase).

Метод void printAllBooks() — печатает все книги.

Метод void printAvailableBooks() — только доступные.

Метод void printStatistics() — выводит:

всего книг

доступных

выданных

всего читателей

Метод boolean lendBook(int bookId, int readerId) — выдаёт книгу читателю.

Метод boolean acceptReturn(int bookId, int readerId) — принимает возврат.

4. Constants (пакет com.library.util)
Требования:

public static final int MAX_BOOKS = 20;

public static final int MAX_READERS = 10;

public static final int MAX_BOOKS_PER_READER = 5;

Никаких других полей и методов.

Класс должен иметь private конструктор, чтобы его нельзя было создать (подумай зачем).

5. InputHelper (пакет com.library.util)
Требования:

public static int readInt(String prompt) — читает число с консоли, обрабатывает некорректный ввод (повторяет запрос).

public static String readString(String prompt) — читает строку.

Внутри — один static Scanner.

Все методы static, класс не создаётся (приватный конструктор).

6. Main (пакет com.library.app)
Требования:

public static void main(String[] args).

Создаёт объект Library, предзаполняет 3–4 книгами через addBook.

Запускает бесконечный цикл с меню:

text
1. Показать все книги
2. Показать доступные книги
3. Добавить книгу
4. Зарегистрировать читателя
5. Выдать книгу
6. Принять возврат
7. Показать читателей и их книги
8. Статистика
0. Выход
Обработка ввода через InputHelper.

При выходе — System.exit(0) или break.

🚫 Ограничения
Не использовать коллекции (ArrayList, HashMap) — только массивы.

Не использовать наследование и интерфейсы.

Не использовать исключения (try/catch) — кроме обработки ввода.

Без файлов, БД, GUI.
